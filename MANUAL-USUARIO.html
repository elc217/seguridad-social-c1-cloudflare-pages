3. Estudiar en la Biblioteca

  1. Abre Biblioteca.
  2. Escribe un número, disposición o palabra en el buscador.
  3. Selecciona la parte de la ley, tipo de contenido o estado.
  4. Abre una unidad para leerla completa.
  5. Usa Abrir este precepto en el BOE para contrastar la fuente oficial.

4. Tarjetas

Las tarjetas entrenan el recuerdo literal mediante fragmentos con palabras ocultas.

Artículo seleccionado

La acción protectora del sistema comprende _____.

Tu tarea: completa el fragmento antes de revelar la respuesta.

  1. Lee el fragmento.
  2. Recuerda la redacción exacta.
  3. Pulsa Mostrar respuesta.
  4. Consulta la cita y la fuente.
  5. Avanza, retrocede o mezcla las tarjetas.

Las tarjetas abiertas y las respuestas reveladas se registran en Progreso.

5. Realizar un test

  1. Abre Test.
  2. Elige el ámbito y el tipo de preguntas.
  3. Selecciona 12, 25 o 50 preguntas.
  4. Pulsa Empezar test.
  5. Responde y comprueba la explicación y la evidencia.

7. Copias de seguridad

Usa Exportar progreso para descargar un JSON. Para restaurarlo, usa Importar copia JSON. Se recomienda exportar antes de borrar datos del navegador o desinstalar una aplicación.

8. Sincronizar con Google Drive

  • Se usa el espacio privado appDataFolder.
  • Solo se sincroniza el progreso.
  • La biblioteca y las preguntas permanecen en la aplicación.
  • La combinación conserva el estado más avanzado.
  • Desconectar no borra el progreso local.

Si aparece «Acceso bloqueado»

La cuenta debe estar añadida como usuario de prueba en Google Cloud mientras la aplicación esté en modo pruebas.

9. Uso sin conexión

La biblioteca, las tarjetas y los tests funcionan sin conexión después de cargar los recursos. Google Drive necesita internet para sincronizar.

10. Aviso jurídico

La aplicación es una herramienta de estudio. Comprueba siempre la legislación vigente en el BOE. No constituye un temario oficial validado.
